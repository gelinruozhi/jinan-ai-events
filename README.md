# 济南 AI 线下活动盘点

面向山东财经大学（章丘校区）计算机专业同学视角，整理 **2026 年 10 月底至 12 月底** 在济南线下举办、且与 AI 相关的活动（黑客松、沙龙 Meetup、大会论坛、Workshop、校园讲座、机器人/算力等）。

- 在线访问：通过 GitHub Pages 发布，仓库根目录即 `index.html`。
- 数据时点：**2026-10-26（周一）**，覆盖窗口为 2026-10 底至 12 底。
- 内容结构：未来活动清单（可按片区/免费/学生可报筛选）、刚结束有复盘价值的、待复核线索、已排查未发现近期活动的渠道，以及相关方法与口径说明。

## 说明

- 只收录「线下 + 在济南 + AI 相关」的活动，每条均附可核验来源 URL，无来源不写。
- 活动时间、地点、报名状态以官方页面实时信息为准，出行前请再次确认。
- 线下活动常临近 3–7 天才官宣/放票，建议每周刷新并关注「待复核」清单与主办方官方渠道。
